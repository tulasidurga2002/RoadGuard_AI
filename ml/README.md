# RoadGuard AI - Machine Learning & Vision Pipeline

This directory contains the Python dependencies and configuration for YOLOv8/YOLOv11 road damage detection model training and offline inference pipelines.

### Setup (Python Environment)
```bash
python -m venv venv
# On Windows:
.\venv\Scripts\activate
# On Linux/macOS:
source venv/bin/activate

pip install -r requirements.txt
```

> **Note**: The web application and Gemini AI integration are served via Node.js / Express / Vite in the repository root (`package.json`).
